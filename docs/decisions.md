# Решения

- **Отдельный репо, а не страница в существующем.** Публичный сервис с собственной
  выкаткой и своими секретами; общих частей с другими проектами нет.
- **Серверный шаблон без сборщика.** Одна форма без JS и без внешних ассетов: стили
  встроены в HTML, отдаётся с `Cache-Control: no-store`, так что проблемы версий ассетов
  за кешем Cloudflare, ради которой правило «всегда сборщик», здесь нет. Появится
  интерактив — переводить на сборщик.
- **Без Telegram-уведомлений.** Стас не хочет получать правки в личку; координатор
  забирает их сам раз в час через `/admin/suggestions`.
- **Лимит по базе, а не в памяти.** Считаем строки с тем же `ip_hash` за час: переживает
  рестарт, отдельного состояния не нужно.
- **Отчёты о счетах — та же база и тот же сервис.** Отдельная таблица `accounts`, тот же
  токен и та же соль: второй сервис ради одной формы не окупается.
- **Голос — только браузерный Web Speech API.** Бесплатно и без нашего сервера; где его нет
  (встроенные браузеры Telegram/Instagram, Firefox), есть диктовка на клавиатуре телефона.
  Серверный STT — только если по данным окажется, что без него не диктуют.
- **Чипы без JS.** Радио и чекбоксы, оформленные CSS; поле «другой» прячется через `:has()`,
  в старых браузерах просто всегда видно. Скрипт нужен только микрофону.
